# 读者故事与具体语言

## 1. 按读者理解顺序讲故事

学术故事不是文学化、虚构情节或研究过程记录，而是把读者从共同起点带到一个经过论证才能接受的结论。

默认路径：

~~~text
读者能够理解的具体情境
→ 原有理解遇到什么困难
→ 因而出现什么问题
→ 现有研究已经回答什么
→ 为什么还缺少关键一步
→ 本文增加什么理由、区分或判断
→ 证据怎样支持这一步
→ 读者最终应怎样重新理解问题
~~~

先让读者看到发生了什么，再告诉读者这个问题在理论上叫什么。

## 2. 让下一步由上一步产生

不要只写“上一节讨论 A，本节讨论 B”。说明 A 完成了什么，又为什么不能回答下一步问题。

因此、进一步、在此基础上等连接词只能标记已经写出的逻辑，不能制造表面连贯。

每节完成后，读者应多知道一件明确的事。重讲背景、换词重复问题、再次强调重要性、罗列作者或从头复述案例，都不构成推进。

## 3. 让每段建立一个主要判断

写作时应能回答：

- 本节正面完成什么；
- 本段正面建立什么；
- 它比上一段新增什么；
- 为什么完成这一段后，下一段才必要。

段落不需要固定句数，但通常包含：

~~~text
本段判断
→ 相关对象、材料或证据
→ 从材料到判断的理由
→ 这一判断怎样推动全文
~~~

段尾优先落在实质判断，不频繁停在“下文将进一步讨论”。

### 3.1 让段落层级显示论证层级

段落不是按句数平均切分，也不是每推出一个小判断就换段。先识别一节中几个真正承担论证任务的步骤，再让每个正文段落完成其中一步。围绕同一主要判断展开的解释、例子、比较和小结通常应留在同一段；只有主要判断、论证对象或推理职责发生变化时才另起一段。

避免两种相反问题：

- 连续使用只有一两句话的小段，把一条完整理由拆成许多同等层级的小台阶；
- 为了减少段数把两个不同的论证职责塞进一个大段，使读者看不出何处已经完成一步。

检查一节的段落层级时，先用普通中文概括每段完成什么。如果多个相邻段只能得到同一个概括，就考虑合并；如果一段需要用两个互不从属的判断才能概括，就考虑拆分。引文、候选回答、公式或列举可以在版面上分行，但不因此成为新的论证段落。

## 4. 优先写可见对象

优先让读者看到：

- 谁在做什么；
- 谁在判断什么；
- 判断对象和依据是什么；
- 哪项材料显示什么；
- 哪些人受到什么影响；
- 最后产生什么不同结果。

遇到主体、机制、路径、维度、层面、规范意义、条件配置、判断位置、规范分量、生成机制、主体资格、规范结构等抽象词时，追问实际是谁、做什么、判断什么、材料显示什么、影响什么。

不优先写：

> 反馈主体的异质性构成了对齐目标生成机制中的规范性张力。

优先写：

> 不同反馈者可能注意到模型回答中的不同问题。选择谁来评价，不仅影响收集到什么反馈，也会影响哪些问题最终进入奖励目标。

## 5. 建立抽象阶梯

抽象概念必须从具体对象中产生，并回到具体判断：

~~~text
具体情境
→ 需要什么区分
→ 引入必要概念
→ 概念如何适用于情境
→ 得到什么规范判断
~~~

长时间停留在概念层、连续使用抽象名词却不回到人、任务、判断或后果，读者就无法知道论证说了什么。

## 6. 节制术语和中文句法

- 能用普通中文准确表达的，不创造术语；
- 权威术语第一次出现时，用一句普通中文说明它解决什么问题；
- 离开自创术语就无法解释的观点需要重新澄清；
- 一句话尽量只完成一个主要判断；
- 主语尽量明确；
- 这、其、该、上述指向不唯一时，改成具体对象；
- 不用连续名词化表达制造学术感；
- 抽象判断后尽快落到案例、任务、数据或模型回答。

### 6.1 保持中文句法成分完整

标点首先标示实际停顿和语义层级，不是看到主语、状语、判断词或引述内容就自动插入。按照《标点符号用法》GB/T 15834—2011，主语与谓语之间、状语之后都是“如需停顿”才用逗号。短而紧密的句法成分在正常朗读中没有停顿时，默认不断开；若直接删除标点仍显生硬，就重写句子，而不是只做机械删号。

#### 6.1.1 先写完整句法，再决定标点

起草时先找出每句话的主语、核心谓语和宾语或补语。先把这条句法主干写完，再判断是否存在需要标示的分句停顿、插入成分或语义转折。不得先按“学术句式”加逗号，再让标点代替没有写完的句法关系。

对每句话依次做四项检查：

1. 删去逗号后，主语、谓语和宾语是否正好构成紧密完整的句子；
2. 逗号前的“指出”“说明”“表明”“认为”“强调”“意味着”“在于”是否正在等待它的宾语；
3. 逗号前的时间、条件或范围短语是否与后面谓语紧密相连；
4. 一句话是否因连续出现三个以上逗号而实际包含两个以上主要判断。

前三项若回答为“是”，默认先删去逗号再朗读。第四项若回答为“是”，优先拆句，不要把所有逗号删掉后留下过长的句子。

#### 6.1.2 高风险模式默认不加逗号

以下模式在普通中文学术句中通常是紧密的动宾、主谓或状谓关系。除非确有较长插入成分、引文格式或避免歧义的需要，默认不在中间加逗号：

- `作者指出评价者可能作出不同判断。`
- `这些材料说明平均结果只概括一部分总体倾向。`
- `这一结果表明差异进入奖励模型后仍可能变得不明显。`
- `这意味着进入训练的是具体人的判断。`
- `本文的研究意义在于把抽象的人类价值问题落到具体评价过程。`
- `反馈进入后续训练以后这些处理选择还可能影响模型行为。`

同样高风险的还有“评价任务要求什么，会影响……”“候选回答怎样提供，会形成……”这类主语小句与谓语之间的逗号。优先改写为：

- `评价任务要求人们判断的内容会影响哪些问题进入反馈。`
- `候选回答的提供方式会影响最终形成什么数据。`

#### 6.1.3 可以保留逗号的情形

不把“少用逗号”误解为“全部删除逗号”。较长的时间、条件或让步分句后确有自然停顿，两个已经拥有各自主谓结构的分句需要分开，以及删去逗号会造成语义歧义时都可以保留。

> 当候选原则会给不同的人带来截然不同的利益和负担时，公平过程需要比较他们提出的竞争性主张。

这里的逗号分隔一个较长的条件分句和主句，保留后层次更清楚。若条件很短，如“反馈进入训练后模型行为可能发生变化”，则通常不需要逗号。

#### 6.1.4 中长篇文本必须做全文级复核

局部发现“指出，”或“在于，”时不得只修正用户指出的句子。对当前稿件搜索以下候选模式，再逐句判断：

- `指出，` `说明，` `表明，` `认为，` `强调，` `意味着，` `在于，`；
- `以后，` `之前，` `时，` `情况下，` `过程中，`；
- 主语性小句后紧接 `会` `能够` `可以` `需要` `构成` `决定` 等谓语时中间出现的逗号；
- 单句内出现三个以上逗号或同时使用逗号、分号和冒号。

这些搜索结果只是候选项，不是错误判定。复核时必须选择三种处理之一：保留有必要的停顿，删除切断紧密句法的逗号，或把承担多个判断的长句拆成数句。修改后再朗读完整段落，避免只删逗号却留下拖沓长句。

重点检查以下模式：

- 不在紧密的主谓结构之间机械加逗号。
  - 生硬：`评价者能够胜任既定任务，回答的是“谁适合完成这项判断”。`
  - 自然：`评价者能够胜任既定任务，只说明谁适合完成这项判断。`
- 不在短状语、时间条件或话题成分之后机械加逗号。
  - 生硬：`核查事实主张时，相关专业知识可能更重要。`
  - 自然：`核查事实主张更需要相关专业知识。`
- 不用逗号切断同一谓语统摄的宾语或补充成分。
  - 生硬：`第三节说明，评价者是否合适，要看具体需要他们完成什么判断。`
  - 自然：`第三节说明评价者是否合适取决于具体任务要求他们完成什么判断。`
- 并列主语或并列宾语与谓语紧密相接时，不在最后一个并列成分后补停顿。
  - 生硬：`有关当前情境的事实、概念说明或背景材料，可以通过评价指引、任务说明或培训提供。`
  - 自然：`有关当前情境的事实、概念说明或背景材料可以通过评价指引、任务说明或培训提供。`

逗号可以保留在确有停顿、避免歧义、突出较长前置成分或分隔复句分句的位置。判断标准不是句法位置上“能不能加”，而是删去以后语义是否仍然清楚、朗读是否更加连贯。

### 6.2 限制标点替代句法

- 冒号用于确实需要提示下文、解释或列举的地方，不把普通谓宾关系改写成“抽象判断：三个分项”。
- 分号用于内部已经含有逗号、层次较复杂的并列分句，不为制造整齐对称而使用。
- 破折号只在重要的插入、补充说明、总结上文、提示下文或意义转换中使用。普通的因果、递进和同位关系优先写成完整句子，不用破折号制造戏剧性停顿。
- 不连续依赖“因此，”“这意味着，”“由此，”和冒号、破折号来显示逻辑。先写清主语、谓语和理由关系，再决定是否需要连接词和标点。

全文通读时朗读长句。若一处标点停顿在中文口语和正式书面语中都不自然，优先恢复完整句法；若一句话连续出现三个以上逗号，检查其中是否混入多个独立判断，并决定删除逗号、改写谓语或拆成两句。逗号数量只是触发检查的信号，不是自动判错标准。

## 7. 用例子让推理可见

区分两种例子：

- 证据性案例证明现实中确实出现某种现象，必须有真实来源；
- 说明性例子展示一条推理如何运行，必须用设想、例如或假如明确标记。

当抽象区分首次出现、概念容易混淆、原则适用不直观、规则产生不同结果或中间推理难以理解时，可以增加简短例子。

举例后必须回到一般论证：

~~~text
提出区分
→ 给出例子
→ 指出真正相关的部分
→ 回到一般判断
~~~

一个核心例子能够贯穿多个步骤时，不要不断更换场景。

## 8. 按论证职责控制重复

同一问题、文献、概念或案例可以再次出现，但要承担提出、解释、应用、比较或综合等新职责。

删除：

- 换词重说同一判断；
- 每节重新介绍整个问题；
- 同一文献反复证明同一结论；
- 同一案例多次从头讲起；
- 同一证据边界反复声明；
- 结论逐段复述正文。

已经完成的理论、事实、例子或边界，后文用最短方式回指；回指后立即增加本节独有的判断。

多个段落不断得到同一结论时，检查是否缺少真正的中间步骤，而不只是做文字去重。
