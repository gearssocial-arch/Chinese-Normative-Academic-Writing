# 证据与学术发布

## 1. 区分材料的认识地位

始终区分：

1. 文献或数据直接呈现的事实；
2. 文献作者自己的主张；
3. 本文根据材料作出的推论；
4. 本文构造的说明性例子。

不得把本文推论或构造例子写成来源事实。

每篇文献、案例、数据、实验、模拟、表格和引文都必须回答：

> 它在这里具体支持哪一步？

没有明确职责的材料不因主题相关就进入正文。

## 2. 保持来源强度与主张一致

禁止：

- 把相关关系写成因果关系；
- 把个案写成普遍规律；
- 把可能性写成已经发生的事实；
- 把作者没有提出的观点归给作者；
- 把模型与人的分歧直接解释成人与人的分歧；
- 把人口属性直接当成评价能力或规范权威；
- 把受到影响直接等同于适合完成所有评价任务；
- 把偏好数据直接等同于规范上应采纳的价值；
- 用计算或模拟证明伦理原则正确。

没有核验的页码不得猜测。工作稿可以标明页码待核验，提交稿不能保留未经核验的精确页码。

不得虚构文献、DOI、页码、数据、作者观点、案例或原文术语。

## 3. 让文献综述推动问题

文献综述不是作者名单和观点摘要的堆积。每组文献都要形成：

~~~text
这些研究已经解决什么
→ 它们与本文问题怎样相接
→ 它们在哪一步停止
→ 本文为什么仍需继续
~~~

不要为了国内外平衡、参考文献数量、作者知名度或主题相近而机械加入文献。文献只有在承担当前论证职责时才进入。

## 4. 把论文写成学术发布

研究过程可以复杂，论文叙事必须清楚。正文不按先尝试什么、后来失败什么、最后补充什么组织。

只保留最终成立的逻辑：

~~~text
问题为什么真实而重要
→ 现有研究为什么还缺少一步
→ 本文增加什么回答
→ 证据怎样支持回答
→ 这个回答为什么值得关注
~~~

论文不平均展示研究的所有方面，而是围绕证据能够支持的最强贡献组织材料。最强结论不能藏在脚注、段尾或材料描述里。

## 5. 不创造无关比赛

论文不以性能、精度、一致性、统一性或完整覆盖为目标时，不要主动把这些维度设成成功标准。

不要把非核心维度的不占优结果提炼成对全文的否定。直接说明本文评价什么、适用于什么条件、解决什么问题。

但不能用目标不同掩盖会推翻核心主张的证据。

## 6. 保留边界，不要穿盔甲

论文不需要预先回应所有质疑，也不需要展示作者想到的每个小问题。

只有以下内容需要进入正文：

- 真正的概念区分；
- 来源和证据的真实边界；
- 推理成立所需条件；
- 会改变主张真假、适用范围或证据强度的事实。

把限定放在它实际约束的论证位置，以中性、具体、简短的方式说明，然后继续推进。

不要为了表现谨慎而增加集中的弱点清单、无关免责声明、所有可能反例的预防性回应，或空泛的未来研究段落。

原则是：

> 小问题不升级，真问题不隐藏；必要边界准确说明，非必要弱点不主动发布。

能够局部修正的问题直接修正，不必在正文中宣布原文存在缺陷。不影响核心结论、主张范围、证据支持或读者理解的小问题，不扩展成局限讨论或新理论分支。

会改变主张真假、适用范围、证据强度或关键推理的问题，必须修正论证、收缩主张或准确说明边界。

## 7. 把防御性语言改成正面主张

重点检查遗憾的是、本文仅仅、仍然存在明显不足、效果有限、当然本文无法、必须承认、需要注意的是、不意味着和不足以说明。

不要机械删除否定词。真实的概念区分、来源边界和推理条件仍要保留。

不优先写：

> A 不能说明 B。

优先写：

> A 回答的是 X；B 还需要 Y。

不优先写：

> 本文并不是提出另一套筛选机制，而只是……

优先写：

> 本文提供的是一条更前置的规范理由：……

正文应告诉读者本文建立了什么，而不是围绕本文没有做什么展开。

## 8. 摘要、引言与结论

### 摘要

按真实问题、相邻研究与缺口、本文思路、最强结果及意义组织。摘要不是正文目录，不堆积文献名、免责声明和局限清单，结尾留下最值得记住的回答。

### 引言

让问题从具体材料中出现，说明为什么值得研究，准确定位相邻研究，指出本文继续完成哪一步。不要提前完整证明核心章节，也不要在贡献出现前集中讨论局限。

### 结论

回到最初问题，压缩全文回答，强化最值得记住的判断并说明其意义。结论不新增理论、案例、文献和限制清单，也不突然自我否定。
