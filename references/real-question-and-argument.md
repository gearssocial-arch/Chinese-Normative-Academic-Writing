# 问题与论证

## 1. 先确认问题确实需要回答

哲学和伦理学问题不必是经验问题，但必须来自真实存在的判断困难、理由冲突、概念混乱、解释缺口或实践选择。

### 1.1 问题必须有具体承载对象

说明问题发生在什么实践、制度、技术安排、材料、判断冲突或论证位置。无法指出承载对象时，警惕它只是抽象词的组合。

### 1.2 不依赖未经证明的前提

不要先假定主体必然冲突、受影响者必然拥有决定权、技术选择必然构成伦理错误、现有研究完全忽略某个问题，或某种偏好天然具有规范权威。

关键事实必须有材料支持。材料只支持可能性时，把问题写成条件性问题。

### 1.3 不把定义重复当作问题

不同答案必须改变某种解释、评价、行动、规则选择或材料理解。答案只是重复定义时，不需要展开研究。

不优先写：

> 代表性不足是否意味着代表不够充分？

更有实质的问题是：

> 当有限反馈者与实际受影响者不重合时，什么理由能够支持前者代表后者作出评价？

### 1.4 准确建立研究缺口

按下列顺序说明：

~~~text
相邻研究已经解决什么
→ 它在哪一步停止
→ 本文继续完成哪一步
→ 这一步为什么不能由已有结论自动推出
~~~

前人没有使用本文的术语，不等于前人没有处理本文的问题。

### 1.5 选择本文能够回答的问题

区分真实且适合本文回答的问题、真实但属于更大研究计划的问题、只作为背景的问题，以及由错误前提或概念混乱产生的问题。

问题宏大不等于贡献更大。选择现有材料、方法和篇幅能够可靠回答的问题。

一个确实需要回答的问题通常可以还原为：

> 在某个具体情境中，已有做法或解释能够完成 X，却不能直接决定 Y；不同的 Y 会改变 Z。因此，本文需要判断……

无法说明 X、Y 和 Z 时，先澄清问题，不要扩写正文。

## 2. 保持一个中心问题

一篇论文只保留一个中心研究问题。辅助问题只能作为回答中心问题的必要步骤。

对每个子问题追问：

> 如果不回答它，中心问题的答案会缺少哪一步？

删除后不影响中心回答的内容，应降为背景、注释或移出主线。

## 3. 保持问题与回答对称

结论必须回答引言真正提出的问题。避免：

- 引言提出规范问题，正文只回答技术问题；
- 开头询问为什么，结尾只描述是什么；
- 开头讨论主体选择，正文转向另一条聚合主线；
- 中途把原问题换成更容易回答的问题；
- 结论扩大到正文从未证明的范围。

中心回答应能用一句普通中文说明。大量自创术语才能解释答案时，论点尚未澄清。

## 4. 写出完整的规范推理

描述性事实不能直接推出规范结论。技术可行性也不能直接推出伦理正当性。

通常需要写清：

~~~text
具体事实或技术安排
→ 哪些主体的什么利益、主张或理由受到影响
→ 采用什么规范判断标准
→ 为什么该标准适用于当前情境
→ 标准如何评价当前安排
→ 得出什么有限结论
~~~

例如，不同反馈者作出不同评价，不能直接推出系统应纳入更多群体。还要说明差异反映什么、哪些差异值得处理、什么原则要求处理，以及结论约束任务设计、主体选择、反馈解释还是聚合规则。

因此、由此可见和这意味着只能标记已经存在的推理，不能代替规范前提。

## 5. 明确原创贡献

不要轻易声称首次、填补空白、尚无人研究、前人忽视或从未有人指出。

更稳妥的结构是：

~~~text
相邻研究已经做到什么
→ 它们停在哪一步
→ 本文进一步完成哪一步
→ 这一步为什么值得完成
~~~

可以使用：

- 本文进一步说明……
- 本文把……与……连接起来……
- 本文为……提供一条规范理由……
- 本文在既有讨论基础上继续追问……

原创贡献必须能用一句普通中文说明。
